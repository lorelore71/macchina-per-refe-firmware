# Smart Ropewalk Rigging Database rev72

Updated 1 November 2026. Compatible with firmware 3.70. No firmware
reinstallation is required: use UPDATE DATA on the machine.

- 359 commercial kit entries: 333 existing entries, 13 additional kits for
  existing vessels and 13 new vessels explicitly approved by Lorenzo.
- Includes Norske Love. The five rejected candidates are not included.
- Existing rigging tables and diameter normalization data are unchanged.
- Le Superbe uses the 74-gun table based on its documented armament.
  Other unverified new Steel classifications remain n.d. No new rigging
  diameters have been invented or interpolated.
- Image manifest rev71 contains 225 files, reusing existing image URLs
  and hashes except for 14 prepared files: 13 new vessels and corrected HMS Diana.
- British original HMS Diana.jpg supplies /ships/Diana.jpg. Spanish original
  diana.jpg supplies /ships/Diana (Spagna, 1792).jpg. The two are distinct.
- The original photographs and Lorenzo's decision workbook are unchanged.

Connect the machine to Wi-Fi, open Update, check online, then choose UPDATE
DATA. The database and missing or changed backgrounds are updated together.
Firmware binaries, manuals, saved presets, Wi-Fi settings and activation are
unchanged. A new firmware installation is not needed.

The optional ZIP contains four data files for /rigging/ and the fourteen new
or corrected JPG files for /ships/. Other backgrounds are not included in
this delta ZIP and remain available through the online image manifest.
Back up your microSD before manual copying.
