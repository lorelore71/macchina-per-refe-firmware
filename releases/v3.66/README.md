# Smart Ropewalk v3.66

- Live Web Simulator: native display pages and touch input, English browser controls, IT/EN/ES instructions.
- Saved presets on SD and internal memory are preserved, including when the schema marker is absent or old. Previously deleted data cannot be recovered automatically.
- Updated IT/EN/ES PDF manuals, including the Web Simulator appendix; automatically downloaded during firmware OTA when newer or missing.
- No changes to motor pin mapping, drivers or acceleration. Database rev70 and ship images rev69 unchanged.

Extract the complete Web Display ZIP and open index.html on a computer connected to the same Wi-Fi network. Disconnecting the browser does not stop the motors. Demo mode remains enforced by the device.

For OTA use the application .bin, not the merged image. The merged image is for complete USB installation and can overwrite stored internal data.
