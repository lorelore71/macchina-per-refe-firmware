# Smart Ropewalk firmware v3.24

Release OTA per display JC3248W535C.

## Novita

- Firmware display portato a 3.24.
- Aggiunta prova sperimentale 71 validata: `14x0,22x3`, 42 trefoli totali, `400/300`, diametro finale `1,97 mm`.
- Regola consigliata: da `2,00 mm` in su tensione `350 g`.
- Aggiunte ricette stimate non validate per `2,20`, `2,40` e `2,60 mm`.
- Editor preset aggiornato con torsioni, avvolgimenti e modifica guidata di trefoli totali/gruppi.
- Simulatore HTML portato a 3.24.
- Database rigging rev58-full invariato.
