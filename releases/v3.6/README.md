# Smart Ropewalk Display Firmware v3.6

Release OTA per display JC3248W535C.

## File

- `firmware-jc3248w535c-v3.6.bin`: firmware applicativo per aggiornamento OTA.
- `firmware-jc3248w535c-v3.6-merged.bin`: immagine completa per flash USB.
- `firmware-jc3248w535c-v3.6-bootloader.bin`: bootloader.
- `firmware-jc3248w535c-v3.6-partitions.bin`: tabella partizioni.
- `SHA256SUMS.txt`: checksum SHA256 degli artefatti.

## Note

- Versione firmware impostata a `3.6`.
- Attivazione tramite licenza legata al MAC del display.
- Demo mode con motori disabilitati se il dispositivo non e' attivato.
- Pagina attivazione aggiunta al manuale.
