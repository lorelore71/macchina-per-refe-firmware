# Rigging database rev71 for Smart Ropewalk 3.68

Updated 2026-10-31. The firmware binary is unchanged: use UPDATE DATA on the machine. No firmware reinstallation is required.

## Contents

- 333 commercial model kits, including Redoutable by Artesania Latina at 1:84.
- Seven Amerigo Vespucci kit entries: OcCre 1:100; Mantua/Panart 1:84; Mantua 1:100; Hachette 1:100; Heller 1:150; Mamoli 1:150 and 1:350.
- Dedicated Amerigo Vespucci table with 249 rigging entries, shared across its kit scales. The chosen scale remains editable.
- 13,421 rigging rows in total: 9,642 with a diameter, 3,779 with diameter unavailable (n.d.). Existing Steel class data are unchanged.
- Ship image manifest rev70 adds the Redoutable background. Other image URLs and checksums are retained; only missing or changed files are downloaded.

## Amerigo Vespucci data limitation

The Vespucci is not assigned a historical Steel class. Its dedicated table contains modelling estimates and analogies, NOT verified measurements of the ship. Entries are marked [ESTIMATE], [STIMA] or [ESTIM.] on the display. All 249 entries carry an RH/LH direction; 83 previously missing directions were assigned by explicit analogy with individual 74-gun rigging items, including the closest applicable level where an exact match is absent. The full provenance and limitations remain in the CSV notes. Missing diameters remain n.d. and cannot be applied to a recipe.

## Updating

Connect the machine to Wi-Fi, open the Update page, search online and select UPDATE DATA. Firmware 3.68 already supports this package. The data and firmware updates do not require a particular installation order.

The optional ZIP contains the data files for /rigging/ and the new Redoutable.jpg for /ships/. It does not replace presets, activation files or Wi-Fi settings. Keep a backup of your microSD card before manual copying.
