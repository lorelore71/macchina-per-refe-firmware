# Smart Ropewalk v3.59

Firmware `3.59` e database rigging `rev69` per display JC3248W535C.

Il database include tutte le `13.172` manovre estratte dalle tavole Steel.
Le `9.429` righe con circonferenza o diametro storico disponibile mantengono
il relativo diametro. Le altre `3.743` righe sono incluse come `n.d.`: restano
ricercabili e consultabili, ma il firmware non permette di applicarle alla
ricetta perche' nessun diametro e' stato stimato.

Il comando **AGG. DATI** continua a gestire database e immagini vascelli in
modo indipendente. Le immagini restano alla revisione `rev67`.
