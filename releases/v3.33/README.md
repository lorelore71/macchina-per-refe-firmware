# Smart Ropewalk firmware v3.33

Firmware OTA per display JC3248W535C.

Novita principali:

- database rigging completo aggiornato a `rev59-full`;
- 30 slot preset, con le 15 ricette cotone predefinite e 15 slot inizialmente vuoti;
- riallineamento una tantum dei preset predefiniti;
- scorrimento touch corretto nelle liste preset, vascelli e manovre;
- selezione diretta del numero pagina dei preset.

Per OTA usare `firmware-jc3248w535c-v3.33.bin`.
