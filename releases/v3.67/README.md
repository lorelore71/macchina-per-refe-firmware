# Smart Ropewalk v3.67

## What's new

- Open Web Display directly at your machine's IP address: no ZIP extraction or application installation required.
- The page connects automatically to the machine you opened.
- Improved fit for landscape tablet screens.
- Updated IT/EN/ES PDF manuals and optional computer ZIP package.
- Motor operation, recipes, activation, rigging database rev70 and ship images rev69 are unchanged.

## Open Web Display

1. Connect the machine and your computer or tablet to the same local network.
2. Read the machine's IP address on its Wi-Fi page.
3. Enter `http://` followed by that address in your browser, for example `http://192.168.1.50/` (replace this with your machine's IP).

Tested with Microsoft Edge on Windows and WebKit using iPad profiles. iPadOS 15 or later is the target requirement; a physical iPad and macOS Safari have not been tested.

The optional ZIP remains available for computer use: extract all files, open index.html, enter the machine IP and click Connect.

**Safety:** this panel controls the real machine. Closing the browser, disconnecting or losing Wi-Fi does not stop the motors. Demo-mode restrictions remain active.

## Manuals

The three PDF manuals are included below and are automatically downloaded during firmware OTA when newer or missing.

For OTA use the application `.bin`, not the merged image. The merged image is intended for complete USB installation and can overwrite internal settings.
