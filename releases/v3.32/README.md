# Smart Ropewalk firmware v3.32

Firmware OTA per display JC3248W535C.

Novita principali:

- calcolo automatico del numero teorico di trefoli tramite la curva `K(D)` del materiale;
- scelta della configurazione pratica sulla griglia delle 15 ricette cotone validate;
- torsioni e avvolgimenti calcolati matematicamente in funzione di diametro del trefolo e trefoli per gruppo;
- preset predefiniti allineati al foglio Excel `Ricette validate`, con RPM `500/500` e tensioni empiriche;
- database rigging `rev58-full` invariato.

Per OTA usare `firmware-jc3248w535c-v3.32.bin`.
