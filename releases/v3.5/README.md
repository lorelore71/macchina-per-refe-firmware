# Firmware v3.5

Release OTA provvisoria per display JC3248W535C.

## Modifiche

- Firmware display portato a `3.5`.
- Export automatico una tantum delle schermate firmware su microSD.
- I BMP vengono salvati in `/screenshots_fw` per italiano, inglese e spagnolo.

## Nota

Questa release contiene una funzione temporanea da rimuovere dopo l'acquisizione raster delle schermate.

## File

- `firmware-jc3248w535c-v3.5.bin`: binario OTA.
- `firmware-jc3248w535c-v3.5-merged.bin`: immagine completa flash.
- `SHA256SUMS.txt`: checksum dei binari.
