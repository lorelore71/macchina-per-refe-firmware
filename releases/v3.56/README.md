# Smart Ropewalk firmware 3.56

## Improvements

- The **Rope calculation** page now recalculates the complete recipe after manually changing **total strands** or **groups**.
- The displayed final diameter is updated to the newly obtainable value.
- Twist count, winding count, estimated final length and recommended tension are recalculated from that new configuration.

## Unchanged

- Rigging database: `rev64`.
- Motor pin mapping, motor control behaviour and activation system.

## Files

- `firmware-jc3248w535c-v3.56.bin`: firmware application for Wi-Fi OTA update.
- `firmware-jc3248w535c-v3.56-merged.bin`: complete image for USB flashing.
- `SHA256SUMS.txt`: integrity hashes for every binary.
