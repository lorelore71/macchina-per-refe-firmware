# Firmware JC3248W535C v3.28

Release OTA per Smart Ropewalk.

## Novita

- Preset ordinati per diametro finale ottenibile crescente.
- Gli slot salvati o generati dalle ricette validate vengono mostrati prima degli slot liberi.
- La numerazione interna degli slot non viene modificata.
- Database rigging `rev58-full` invariato.

## File

- `firmware-jc3248w535c-v3.28.bin`: firmware applicativo per aggiornamento OTA.
- `firmware-jc3248w535c-v3.28-merged.bin`: immagine completa per flash USB.
- `firmware-jc3248w535c-v3.28-bootloader.bin`: bootloader.
- `firmware-jc3248w535c-v3.28-partitions.bin`: tabella partizioni.
