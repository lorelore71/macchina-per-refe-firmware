# Smart Ropewalk firmware v3.31

Release OTA per display JC3248W535C.

## Contenuto

- `firmware-jc3248w535c-v3.31.bin`: firmware applicativo OTA.
- `firmware-jc3248w535c-v3.31-merged.bin`: immagine completa per flash seriale.
- `firmware-jc3248w535c-v3.31-bootloader.bin`: bootloader.
- `firmware-jc3248w535c-v3.31-partitions.bin`: tabella partizioni.
- `rigging_bundle_rev58.csv`, `rigging_classes_rev58.csv`, `ships_rev58.csv`, `rigging_db_rev58.csv`, `diameter_normalization_rev58.csv`: database rigging e normalizzazione diametri.

## Note

- Regola trefolo singolo: soglia minima sperimentale `3200` torsioni ogni `180 cm`, applicata solo alle ricette con un trefolo per gruppo.
- Prova poliestere corretta come prova `80`, non `91`.
- Database rigging invariato: `rev58-full`.
