# Smart Ropewalk v3.60

Firmware `3.60` e database rigging `rev70` per display JC3248W535C.

La revisione normalizza tutte le scale commerciali nel formato `1:N` e
completa le scale disponibili dei kit privi di classe Steel. Le classi Steel,
le manovre, i diametri storici, il mapping motori e le ricette non cambiano.
Il catalogo arriva a 360 kit e i modelli senza classe Steel restano
consultabili senza mostrare manovre assegnate per errore a un'altra classe.
