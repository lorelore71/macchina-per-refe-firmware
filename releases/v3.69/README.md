# Smart Ropewalk 3.69

## What changed

- Ship selection now shows four columns: ship name, kit brand, Steel class and scale. Longer brand names are abbreviated on screen; the original database remains unchanged.
- The rigging list still shows five entries per page, with taller rows and more usable space for two-line descriptions. The database footer is below the list.
- Updated Italian, English and Spanish PDF manuals with current screenshots and callouts; updated optional Web Display ZIP.
- Motor control, pin mapping, calculation formulas, saved presets, Wi-Fi settings and activation are unchanged.
- Rigging database rev71 and ship images rev70 are unchanged and remain available through Update Data. No new data download is required for this layout update.

## Install and use

Use the application `.bin` for OTA, not the merged image. The merged image is for complete USB installation and can overwrite internal settings.

The PDF manuals are downloaded automatically during firmware OTA when newer or missing. They are also attached separately. Saved recipes are preserved.

Open `http://` followed by the display IP in a browser on the same Wi-Fi network. Reload after updating. The Web Display reproduces the updated machine pages automatically. Alternatively, extract the optional ZIP and open index.html on a computer; instructions are included in English, Italian and Spanish.

Safety: this interface controls the real machine. Closing the browser or losing Wi-Fi does not stop motors. Demo-mode restrictions remain active. iPadOS 15 or later is the target; physical iPad compatibility has not been certified.
