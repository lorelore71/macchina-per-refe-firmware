# Smart Ropewalk firmware v3.25

Release OTA per display JC3248W535C.

## Novita

- Firmware display portato a 3.25.
- Validata prova sperimentale 74: `1x0,22x2`, `3200/1500`, `150 g`, diametro finale `0,35 mm`.
- La prova 69 resta registrata ma non e' piu' ricetta validata.
- Normalizzazione testo rigging per display: accenti, apostrofi tipografici e trattini lunghi vengono convertiti in caratteri compatibili col font LVGL.
- Database rigging rev58-full invariato.

## File

- firmware-jc3248w535c-v3.25.bin: firmware OTA.
- firmware-jc3248w535c-v3.25-merged.bin: immagine completa per flash via USB.
- firmware-jc3248w535c-v3.25-bootloader.bin: bootloader.
- firmware-jc3248w535c-v3.25-partitions.bin: tabella partizioni.
- rigging_bundle_rev58.csv: pacchetto unico database per aggiornamento su microSD.
