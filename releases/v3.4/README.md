# Firmware v3.4

Release OTA per display JC3248W535C.

## Modifiche

- Firmware display portato a `3.4`.
- Pagina Wi-Fi aggiornata: rimosso campo ESP32 IP.
- Aggiunto pulsante `RESET WIFI` per cancellare SSID, password e profili Wi-Fi salvati.

## File

- `firmware-jc3248w535c-v3.4.bin`: binario OTA.
- `firmware-jc3248w535c-v3.4-merged.bin`: immagine completa flash.
- `SHA256SUMS.txt`: checksum dei binari.
